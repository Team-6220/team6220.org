new site, and what the new pages still lack. Collected Nov 9, 2026 from the live pages' HTML (`curl` of every page in
the sitemap plus the pages in the menu) and read-only Wix API calls (site properties, SEO user config). Nothing on the
Wix site was changed.

## What was imported in this change

In `sites/main/MainLayout.astro` (public pages only, not the apps), values in `sites/main/data/seo.ts`:

- `og:type`, `og:site_name`, `og:image` (+ width/height), `twitter:card`, `twitter:image`: the old values.
- `og:title`, `og:description`, `twitter:title`, `twitter:description`: set to each page's own title and
  description, which is how the old site worked (its social text equalled its page text).
- `google-site-verification`: the old Search Console tag.
- Home page only: the old `WebSite` JSON-LD.

## What could not be read

- **Wix dashboard SEO settings** (per-page "hide from search results", the URL Redirect Manager contents, the
  Robots.txt Editor, Marketing Integrations such as Google Analytics): the REST endpoints tried returned only the SEO
  user config and site properties. The redirect list endpoint returned 404. Indexing status was taken from the live
  HTML (no `noindex` anywhere) instead.
- **Google Search Console:** no access from here; only the verification tag is known.
- **Page-level SEO that Wix hides from the HTML** (for example SEO "advanced" structured data per page) is not
  visible; only JSON-LD present in the HTML was captured (the home `WebSite` block only).
